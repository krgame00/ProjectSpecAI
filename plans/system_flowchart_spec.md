# 📐 PCSpec System Flowchart & Architecture Specification

## 1. 🏗️ สถาปัตยกรรมและตำแหน่งไฟล์ (File & Architecture Mapping)

| หัวข้อ Flowchart | Frontend Component / View | Backend Controller / Route | Database Table / Service | SVG File Path |
| :--- | :--- | :--- | :--- | :--- |
| **1. สมัครสมาชิก** | `AuthModal.vue` | `routes/authRoutes.js` (`/register`) | Table: `users` | `docs/flowcharts/1_register.svg` |
| **2. เข้าสู่ระบบ** | `AuthModal.vue`, `auth.js` | `routes/authRoutes.js` (`/login`) | Table: `users` (JWT Auth) | `docs/flowcharts/2_login.svg` |
| **3. จัดสเปคด้วยตนเอง** | `BuilderView.vue`, `builder.js` | Direct Pinia State & State Sync | Catalog Cache / Memory | `docs/flowcharts/3_builder.svg` |
| **4. ใช้ระบบ SpecAI ช่วยจัดสเปค** | `BuilderView.vue` (SpecAI) | `routes/chatbot.js` (`/generate-spec`) | Gemini AI Service | `docs/flowcharts/4_specai.svg` |
| **5. ใช้แชตบอทถามข้อมูลเกี่ยวกับคอม** | `ChatbotModal.vue` | `routes/chatbot.js` (`/message`) | Gemini AI Service | `docs/flowcharts/5_chatbot.svg` |
| **6. ระบบเพิ่มข้อมูลอุปกรณ์** | `AdminView.vue` | `routes/hardware.js` (`POST /`), `upload.js` | Table: `hardware_components` | `docs/flowcharts/6_admin_add.svg` |
