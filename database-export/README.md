# 🗄️ Database Inspector & Data Dumps

โฟลเดอร์นี้รวบรวมไฟล์ข้อมูลและผังแสดงผลฐานข้อมูล MySQL (`smart_pc_builder`) ของโปรเจกต์ PCSpec

## 📁 รายชื่อไฟล์ในโฟลเดอร์นี้

1. **`database_view.html`**
   - ไฟล์หน้าเว็บเดี่ยว (Standalone HTML Viewer) สไตล์ Supabase Dark Mode
   - ดับเบิลคลิกเปิดดูผ่านเบราว์เซอร์เพื่อดูข้อมูลทุกตาราง มีระบบสลับแท็บและช่องค้นหาด่วน (Live Search)

2. **`all_database_data.json`**
   - ไฟล์ข้อมูลดิบทั้งหมดในฐานข้อมูลในรูปแบบ JSON

---

## 🔄 วิธีอัปเดตข้อมูลล่าสุดจาก MySQL

หากมีการเพิ่ม/แก้ไขข้อมูลในฐานข้อมูล และต้องการอัปเดตไฟล์ในโฟลเดอร์นี้:

```bash
cd node-backend
npm run export-db
```
ระบบจะดึงข้อมูลสดจาก MySQL มาเขียนอัปเดตไฟล์ลงในโฟลเดอร์ `database-export/` ให้อัตโนมัติครับ
